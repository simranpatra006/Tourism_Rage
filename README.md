# 🌍 Tourism Experience Analytics

## How to Run
1. Install dependencies: `pip install streamlit pandas numpy scikit-learn plotly`
2. Run the app: `streamlit run app.py`
3. Open browser at `http://localhost:8501`

## Features
- Predict attraction ratings (1-5)
- Predict visit mode (Business/Family/Couples/Friends/Solo)
- Get personalized attraction recommendations
- Interactive dashboard with 6 visualizations

## Design
- Neo-Brutalist UI with bold colors and chunky borders
- Fully responsive
- Mobile-friendly
